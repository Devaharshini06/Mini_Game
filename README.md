# Softcube

An original 3D cube obby. You are a pink cube. The course is pink and blue blocks. Sound is generated ASMR, not a music track.

Inspired by the parkour-obby idea — not a copy of Rainbow Obby.

```bash
npm install
npm run dev
```

Open http://localhost:5174

- Move: WASD or arrows
- Hop: Space
- On a phone: stick + hop
